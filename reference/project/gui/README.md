# NullHarbor project GUI reference

This directory contains project-owned visual reference material for the native
NullHarbor / Codename Subspace interface.

`nullharbor_modular_gui_reference_20261002.png` is REFERENCE ONLY:
- do not load it as a runtime texture;
- do not ship it as a flattened HUD;
- do not reproduce the sheet literally;
- use it to guide reusable native GUI primitives, spacing, hierarchy, states,
  radial menus, status cards, command surfaces, and restrained sci-fi styling.

Runtime UI remains native/project-owned and should be assembled from modular
widgets/components rather than baked screenshots.
