# EVE-Depth PvE/Co-op Feature Matrix — 2026-08-31

Purpose: preserve the breadth and systemic texture that make an EVE-like sandbox compelling while explicitly replacing involuntary PvP/MMO assumptions with solo/PvE/co-op systems and retaining Subspace's direct flight/modular construction identity.

| EVE-style concept | Subspace disposition | Native direction / remaining work |
|---|---|---|
| Open career sandbox | EXPAND | Combat, mining, salvage, exploration, trade, logistics, industry, stations, planets and fleet command remain parallel careers. |
| Ship fitting | EXPAND | Physical power/heat/mass/hardpoint capacity; add production fitting UI, ammo/charges/fuel and richer meta variants. |
| Ship classes | EXPAND | Frame/scale envelope plus emergent specialization; add much broader class/frame catalog. |
| Drones | EXPAND | Combat/mining/salvage/repair/cargo; add physical deployment AI, control capacity and replacement economy. |
| EWAR | ADAPT | Jammer/target painter foundation exists; expand disruption, missile defense, sensor/power support for PvE. |
| Logistics/support | EXPAND | Remote repair foundation exists; add power/fuel/ammo transfer, rescue/towing and fleet buffs. |
| Mining | EXPAND | Direct lasers/fracture missiles/drones plus enormous streamed belts/rings and survey intelligence. |
| Salvage | EXPAND | Wreck recovery and salvage equipment; add physical dismantling/value tiers/rights and large wreck sites. |
| Local markets | ADOPT + EXPAND | Order matching exists; add NPC supply/demand coupling, market history, hauling tools and regional arbitrage UI. |
| Contracts/agents | ADAPT | Multi-career contract authority exists; add station contacts, generated chains, faction catalogs and authored arcs. |
| Standings/reputation | ADOPT | Gate prices/services/blueprints/permits/territory and NPC reactions. |
| Blueprints/research | ADAPT + EXPAND | Blueprint/material/time/reverse-engineering authority exists; add copies/licenses, variants and production jobs. |
| Exploration signatures | ADOPT | Probe resolution/bookmark/escalation foundation exists; add scanning UI, site content and temporary Subspace routes. |
| Wormhole-like routes | ADAPT | Temporary Subspace tears should have stability/lifetime/mass/hazard characteristics. |
| Abyss-like pockets | ADAPT | Optional unstable PvE expedition pockets with environmental specialization and extraction pressure. |
| Incursion/campaign-scale PvE | EXPAND | Sector Crisis accepts multi-career contributions; add persistent NPC campaigns and world-state consequences. |
| Security geography | REPLACE | Core/frontier/deep/anomalous PvE threat + environmental hazard tiers instead of PvP security. |
| Corporations | EXPAND | Hire/permission foundation exists; add corporation wallet, offices/assets/jobs/divisions and co-op ranks. |
| Fleets | EXPAND | Captain assignment exists; add wings, formations, doctrine roles, fleet logistics and RTS-scale orders. |
| Structures | EXPAND | Freeform modular station authority exists; add production builder, damage/services/defense and off-screen simulation. |
| Planetary industry | REPLACE + EXPAND | Survey -> tether -> space elevator -> Planetary Manufacturing with regional extraction/processing/logistics/orbital export. No direct ship landing. |
| Insurance/loss | ADAPT | Preserve meaningful losses without wiping the persistent corporation; tie recovery to stations/fleets/wrecks. |
| Sovereignty | REPLACE | PvE claims, leases, settlement/infrastructure influence and frontier control instead of player territorial warfare. |
| PvP/ganking/gate camping | EXCLUDE | PvE/co-op is the foundation. Equivalent risk comes from NPCs, crises, hazards and logistics distance. |

## Highest remaining EVE-depth gaps

1. NPC corporations with persistent production/consumption/ship-loss feedback into local markets.
2. Production-grade fitting/market/contracts/system-map interfaces.
3. Ammunition, missile, fuel, repair-part and drone consumable economy.
4. Full fleet hierarchy and support/logistics doctrine behavior.
5. Rich procedural mission/site/escalation libraries.
6. Advanced exploration intelligence: probes, D-scan-like local awareness, bookmarks, temporary routes and sellable survey data.
7. Station-service diversity, shipyards, repair/refit/reprocessing efficiency and ownership/permissions.
8. Faction-specific equipment/blueprint/reputation catalogs and dynamic NPC conflict.
9. Insurance, wreck recovery, rescue and persistent asset-loss UX.
10. Co-op corporation authority/network replication and permission enforcement.
