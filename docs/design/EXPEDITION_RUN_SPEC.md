# Expedition Run Spec

## Purpose

Expeditions are the roguelite layer. They are generated, risky, and reward extraction decisions.

## Run phases

1. Planning
2. Launch
3. Active exploration
4. Extraction available
5. Extracted or failed
6. Reward/consequence application to home system

## Run types

- mining survey
- salvage recovery
- combat patrol
- anomaly scan
- fuel harvest
- blueprint hunt
- free roam

## Failure model

Failure should not wipe the home system. Default loss applies to expedition ship condition/cargo, while black-box analysis can still grant small research progress.

## Reward model

Rewards feed home progression:

- cargo commodities;
- credits;
- blueprint progress;
- research data;
- discoveries;
- faction standing later;
- rare materials later.
