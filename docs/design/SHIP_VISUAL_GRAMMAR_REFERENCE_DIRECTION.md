# Subspace Ship Visual Grammar — Reference Direction

The active ship-art direction favors original modular hard-surface spacecraft with:

- a strong readable command/cockpit section,
- a structural spine rather than stacked hull blocks,
- separate hull, cargo, machinery and propulsion masses,
- visible functional hardpoints,
- exposed main/retro/maneuvering thruster modules,
- negative space between major assemblies,
- large smooth armor fields contrasted with smaller dense mechanical regions,
- layered armor/fairing treatment,
- restrained vents, radiators, conduits and maintenance detail,
- coherent material families and manufacturer/faction visual DNA,
- close-range decals and navigation scale cues,
- role-specific proportions instead of random module scattering.

The current Pinterest modular-ship reference supplied by the project owner is used only as a high-level visual-direction reference. No artwork or geometry is to be copied directly.
