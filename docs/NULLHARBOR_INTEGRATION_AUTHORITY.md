# Nullharbor Integration Authority

Codename Subspace is the unified game/project identity. Nullharbor is a retained source-design lineage, not a parallel game. Approved Nullharbor systems are normalized into Subspace's native C++ runtime and canonical data model.

Retained lineage includes cockpit/direct flight, traversable interiors, docking/hangars, EVA/on-foot gameplay, FPS salvage and intact-module recovery, carriers/hangar craft, drones, R.I.G./powered suit progression, scanning, security ratings, hidden/unknown factions, corporation/fleet command, planetary installations, territorial hex gameplay, broad gameplay settings, debt-start options, and learn-by-doing progression.

Every retained feature must have one current Subspace owner/spec and one roadmap maturity entry. Duplicate game authorities are forbidden.
