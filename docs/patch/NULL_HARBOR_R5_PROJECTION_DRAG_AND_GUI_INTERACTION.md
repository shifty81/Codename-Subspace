# Null Harbor R5 — Projection-calibrated interaction and GUI behavior

**Implementation slice** (not entire GUI re-skin). Baseline: published GREEN `163a770d3ae4406e2cbb581c23ad1765c7b07522`. Only apply with exact source preimages; the internal PCC retains authority.

The prior Studio system froze the onscreen gizmo handle but moved model and assembly entities using `.012 / legacy camera zoom` meters or grid units per pixel. This ignores the renderer perspective, assembly world scale and camera depth. R3/R4 fixed visibility without fixing the input-to-object transform. R5 projects a real physical one-authoring-unit step from the selected entity for every XYZ axis, freezes that pixel derivative on mouse-down, and maps **absolute displacement from the original pointer press** to original authored units. This avoids incremental drift and mouse-handle snap; inspector snaps and legacy builder transactions are preserved. Ship yaw and width/length/height scaling are mapped in the same builder path that draws the gizmo. Model XYZ uses direct physical units. Dynamic UI reflow retains physical calibration even if the tip is relocated.

A camera-facing axis has near-zero screen projection and cannot mathematically follow a cursor across the screen. It uses an explicitly bounded, deterministic depth-drag sensitivity derived from the other visible axes; prefer orbiting for direct visual tracking. This is a controlled fallback, not geometric screen tracking. Rotation and scale retain current controls in this slice: they still require a separately specified ring/scale handle rewrite.

GUI behavior: ordinary body click always selects; only a visible axis handle begins constrained move/rotate/scale. Deliberate Ctrl+drag of the already-selected object retains legacy free-transform/socket behavior, and startup help describes controls. This eliminates unexpected object dragging on simple clicks while preserving existing capabilities and input shortcuts. The detailed R5 dock/Inspector redesign, DPI/reflow, tooltip normalization, renderer-owned drag visual guides and unified input/layout snapshots remain a FOLLOW-UP, not certified by this patch.

Certification: existing CTest projection test retains its 4,940 sample sweep and adds model/assembly pixel-to-authored-unit, reversed axis, fine movement, dock reflow calibration, depth fallback and nonfinite pointer tests. Compare rendered pixel movement to pointer movement in real Studio at multiple zoom/angles, with snap off first then on. Check no stale application binary.
