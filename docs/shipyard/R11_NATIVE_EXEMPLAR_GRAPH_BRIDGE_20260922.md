# R11 — Native Studio blueprint intake + draft graph-grammar compiler

**State:** candidate patch; portable focused tests only. Windows PCC Full Gate and visual/functional acceptance NOT RUN. **Published source baseline inspected:** `a08a5d09f3b01a4e6fa134c0015d35ab9bb20c17`. **Prerequisite:** R10 exemplar intake must be installed, because both R11 Python programs import `tools/shipyard/exemplar_intake.py`. This patch does **not** contain R10, R9, an engine binary, donor Blender sources, or a source rollup.

## Source-exact discovery that dictates the fix

The actual native `engine/src/ship_editor/ShipBlueprintLibrarySystem.cpp` saves `SUBSPACE_SHIP_BLUEPRINT_V1`, `MODULE` placement rows **without instance IDs**, and `ATTACH parentModuleIndex childModuleIndex parentSocket childSocket measuredGap certified`. The native Studio store delegates `.subspace_ship` saves to that codec. The Blender extension instead exports `subspace.shipyard_design` v1 with `instanceId` and explicit connection names. These are different authoritative file formats; renaming a file or assuming Blender JSON would silently corrupt exemplar identity.

The native codec also serializes yaw/pitch/roll independently of the Blender export's `rotationEulerDeg`, can store mirrorX/Y/Z, and includes a `certified` attachment flag. That flag is a saved assertion, not proof that the current geometry still matches its former certificate. No current physics/mesh validation is performed by this patch. The native blueprint is preserved byte-for-byte.

## Actual changes (new files only)

- `tools/shipyard/native_blueprint_intake.py` strictly parses the native V1 text-format export, maps actual index links, retains catalog classifications and separate native transform/mirror/material evidence, and emits the same *shape* of staged R10 candidate and audit. Native instance names are source-SHA-prefixed **provisional ordinal labels**, not durable object IDs. Unknown V1 row types, missing parent indices, multiple parents, NaN transforms, duplicate metadata or oversized input are rejected. Native files without a Grade-A catalog remain class-unverified. Saved uncertified links and measured gaps are exposed as warnings; absent durable identities and physical validation remain blockers. It NEVER writes a native blueprint, calls the native game, or promotes a catalog asset.
- `tools/shipyard/exemplar_graph_compiler.py` consumes one to 32 R10/R11 candidate-and-audit pairs. It rechecks the structural graph (one root, complete N-1 edges, unique instance IDs, connectedness, matching node/module/semantic references), blocks invalid or previously promoted input, groups only consistent role exemplars, rejects duplicate source hashes, and emits deterministic observed **semantic socket patterns**, **exact asset/socket pair frequencies**, module-option observations, approximate symmetry hints, source hashes, root identities and a construction-order index. Native and Blender input use the same downstream graph representation; no second runtime generator is introduced.
- `tools/shipyard/tests/test_native_blueprint_intake.py`, `tools/shipyard/tests/test_exemplar_graph_compiler.py`: targeted unit/failure/regression checks and an end-to-end native-source -> candidate -> grammar test that asserts source bytes remain unchanged.
- `scripts/subspace_exemplar_r11_gate.ps1`: PowerShell 5.1-friendly focused optional Python test command. It is not grafted into PCC and does not certify runtime.

## Scope boundaries

Both programs output **review-only** data. The grammar has `PROPOSED_UNCERTIFIED`, `generatorEligible=false`, `runtimeExecutable=false`, `sourceMutationAllowed=false`, and cannot be installed as a C++ generator recipe. Observed module IDs are **NOT certified interchangeable replacements**. `worldPositionDeltaMeters` is not a socket-local pose and does not prescribe transform math. An example's class, topology, 3D collisions, socket normal, interior, propulsion, materials, license, silhouette or class-envelope safety cannot be certified from native text or Blender JSON alone. No actual new ships are generated by R11.

## Windows commands — R10 first, then R11

Put only R11 `.patch` unextracted in the repository root and approve it via internal PCC after R10 is installed. Run PCC option 1 and the focused tests:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\subspace_exemplar_r11_gate.ps1
```

For an actual Studio-saved ship, with the **real hydrated certified** CSV catalog:

```powershell
python .\tools\shipyard\native_blueprint_intake.py `
  --input 'C:\Path\To\AuthoredFrigate.subspace_ship' `
  --catalog '.\content\derived\greyoxide_shipyard_v07\certified\certified_module_catalog.csv' `
  --out-dir "$env:TEMP\SubspaceExemplars\NativeFrigate"

python .\tools\shipyard\exemplar_graph_compiler.py `
  --exemplar-dir "$env:TEMP\SubspaceExemplars\NativeFrigate" `
  --grammar-id 'player-mining-frigate-v1' `
  --output "$env:TEMP\SubspaceExemplars\Grammars\mining-frigate-review.json"
```

For a two-example family, run the R10 Blender-intake script in a **second output directory** and append `--exemplar-dir '...BlenderFrigate'` to the compiler invocation. Use a common role; incompatible role or duplicate source is rejected. Outputs are staging-only, and existing files require explicit `--overwrite`. Preserve original blueprint and source catalog.
